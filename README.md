# Tensorflow replication

The purpose of this repo is to report the bugs found by [Pynguin](https://www.pynguin.eu/) in [tensorflow](https://pypi.org/project/tensorflow/).

It is organised by module at the origin of the crashes where:

- `<test>.py` is the minimal test recreated manually
- `<test>.raw.py` is the raw test generated by Pynguin
- `<test>.log` is the result of the execution of the minimal test by Pytest

## Installation

```bash
python -m venv venv
source ./venv/bin/activate
pip install -r requirements.txt
```

## Running the tests

```bash
pytest -vs <path-to-test>
```
